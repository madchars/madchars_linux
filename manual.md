# Creación de memoria booteable
## Memoria con S.O. Linux Mint
Una memoria booteable sirve para tener un sistema operativo portable o de arranque. Para este caso en especifico, se usará Linux Mint como sistema operativo portable.
### Materiales
* LinuxMint.iso
* Memoria USB de +16GB
* Rufus 

### Pasos para crear la memoria.

Paso 1: Descargar la imagen iso [https://linuxmint.com/download.php] y rufus portable de [https://rufus.ie/es/]

Paso 2: Crear una carpeta y guardar ambos archivos dentro de está.

Paso 3: Introduce la memoria en el puerto USB y ejecuta rufus

Paso 4: Damos clic en aceptar cuando nos pida permiso de ejecutarse.

Paso 5: Seleccionamos la manera de arranque y el archivo a escoger. Donde nos abre nuestro explorador de archivos y abrimos nuestra carpeta donde metimos los archivos y seleccionamos LinuxMint.

Paso 6: Le damos en "empezar" y "ok en las demás ventanas que nos abra, y se empezará a ejecutar y formatear
